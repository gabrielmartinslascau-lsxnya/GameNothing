# GameNothing
Native PC gaming with Steam, Epic, GOG and Amazon integrations on Android. but a LOT better looking. with a few extras

emulate any game, right now, on your phone. just a simple install, and custom built UI options, and more coming soon
log-in with steam for example, just download, and play. online or offline!
here's what Gamenothing or GameNative-LSX will bring for you :

- more animations
- glass panel UI
- colour picker
- haptics
- 144hz support
- nothing style font
- multiple logos to choose
- steam emulation
- GOG emulation
- Amazon games emulation
- Epic games emulation
- custom games (external or internal)
- cloud saves
- nexus mods
- local mods
- and a whole lot more!
